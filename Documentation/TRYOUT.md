# 0.2 试用说明

## 获取与安装

1. 打开仓库 Actions，选择最新**成功**的 `Build Personal Fitness trial`。
2. 下载 `PersonalFitness-unsigned-ipa` artifact，解压取得 IPA、SHA256 和 BUILD-INFO。
3. 使用匹配的个人签名与 provisioning profile。默认 Bundle ID `com.personalfitness.private`；HealthKit entitlement 必须由最终 profile 允许，不能只修改 plist 假装授权。
4. 在 iOS 27.0 或以上安装。先验证启动、退出重开和基础健康读取；没有真机证据前不宣称完成 P0。

程序不会申请写入 Apple 健康。HealthKit 空结果可能来自未记录、未同步、范围或读权限，不能简单解释为“已拒绝”。睡眠/HRV 等完整健康能力尚未实现。

## 建议按这条路径试

1. 首次打开应无虚构计划或成绩。可在档案中填写已知资料，未知留空。
2. 创建手动计划，选择熟悉且符合自己限制的动作，设置组数/目标，明确确认生效。表单初值不是算法处方。
3. 开始训练，填写实际重量/次数或时间/距离，完成一组。确认保存成功后查看计时。
4. 试暂停、恢复、收起训练、退出重开；已保存组应还在。未离开输入框/未提交的草稿不能保证强制终止后保留。
5. 正常或提前结束，查看历史。修改计划副本后应产生 v2，旧训练仍引用原版本。
6. 在设置导出加密备份，并用口令验证恢复。恢复会替换当前库，先核对说明和数量；有未结束训练时不能恢复。

## 数据边界

- 每次显式保存失败会显示错误并保留原记录；不要将看到输入框数值等同于已完成持久化。
- 历史在本批次只读，没有无提示清除入口；档案暂未提供完整变更时间线。
- 恢复前保护副本留在 App 沙盒并受系统 Data Protection 保护，当前没有单独的“一键撤销恢复”界面。对外备份是独立加密文件，口令丢失不能找回。
- 升级时保留相同 Bundle ID 并覆盖安装；不要通过卸载再安装作为更新方式，卸载会清除 App 沙盒。更新前保留备份。
- AI需本人配置服务后明确发送，支持记录解释和现有计划保守减量；自动计划/恢复评估尚未实现。部分动作有真实离线示范短片，全库GIF与完整教学视频仍未提供，具体见素材来源。

AI与动作库具体试用步骤见 [功能状态](CAPABILITIES.md)。本轮数据库从V1轻量升级到V2，备份格式2兼容读格式1；0.1旧版不支持读取格式2的新备份，请勿降级后覆盖当前数据。

## 反馈
