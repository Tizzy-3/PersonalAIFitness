# AI 教练：连接与数据边界

## 连接自己的服务

在「AI 教练 → AI 接口」填写完整的 **HTTPS Chat Completions 地址**、服务给出的模型名称和 API Key。例如服务的基地址为 `https://你的服务/v1`，通常完整地址为 `https://你的服务/v1/chat/completions`；请以服务文档为准。此适配器不自动改写地址，也不跟随 HTTP 跳转。

仅支持非流式 Chat Completions 文本 JSON；Responses API、网页、SSE 地址或某些特殊模型协议需要另外适配。为了兼容不同服务，请求只提供 `model`、`messages` 和 `stream:false`，不强制服务支持 tools、JSON Schema 或专有参数。输出的结构约定由提示词和本地解析器共同检查，不满足约定时不会作为有效建议保存。

点击保存只保存配置，不发送资料。「测试连接」只发送一条不含档案或训练内容的短消息。接口返回有效文本只能证明该次协议调用成功，不能证明训练建议正确，也不能替代真实模型质量验证。测试使用当前输入，只有点击保存才会持久化配置。

API Key 使用本机 Keychain `kSecAttrAccessibleWhenUnlockedThisDeviceOnly`，不进入 UserDefaults、训练数据、备份和日志，按 HTTPS host 与有效端口隔离。换服务器后不会把原服务器密钥发给新地址。签名团队或 Keychain 权限发生变化时可能需要重填密钥；没有通过训练备份迁移密钥的功能。

接口地址与模型名称保存在本机 UserDefaults，也不包含在训练备份中；在新安装或新设备恢复训练备份后，需要重新配置接口与密钥。

## 每次发送的数据

1. 输入问题或选择提问起点。快捷问题只填入输入框，不自动请求模型。
2. 点击预览。页面显示最终地址、模型，以及之后会发送的实际 JSON。
3. JSON 包含问题、脱敏档案、当前计划、最近最多10次训练和近28天程序统计，并按问题和计划附最多8个本地动作的通用提示。运动限制只发送存在标记，训练记录的备注不发送；动作目录提示尚未经过专业教练逐项验收，不是针对本人的动作评估。没有接入完整 HealthKit 摘要，不发送睡眠、HRV 等健康指标，也不虚构这些数据。
4. 明确确认发送后才联网。没有自动后台请求、自动重试或默认示例回答。服务可能留存请求，请使用本人信任的服务。
5. 模型回答和本次结构化依据保存在本地，可随加密训练备份导出。保存失败时显示未保存回答，可重试保存，无需再次付费请求模型。尚未保存的回答离开页面后可能丢失。

回答中的统计以界面直接展示的本地确定性计算为准。模型只能引用发送过的依据 ID；这限制了来源范围，并不能证明回答正文的每句话准确。模型解释、未知信息与实际记录分别展示。

## 建议与确认

当前支持问答、计划解释和近期训练复盘。AI 计划建议仅限对当前计划同顺序、同动作的保守减量：不增加组数、次数或时长，不缩短休息，不规定重量；休息每项最多增加600秒。动作新增/替换、自动生成训练周期和恢复状态评估仍未实现。

有运动限制标记时，不接受 AI 计划变更建议，仍可回答信息性问题。建议必须通过严格结构、真实动作引用和保守边界校验。界面展示原方案、建议方案、原因与数据依据，由本人拒绝或明确确认。确认时再次检查计划和相关输入是否变化、建议是否超过7天；过期或不一致需重新分析。确认成功才生成生效计划新版本；拒绝保持原计划，既有训练快照不改写。

JSON 校验失败、未知依据、空回答、模型拒答、截断、HTTP 401/403/429/5xx、非 JSON 网页、网络中断、超时或用户取消，都不会更改训练计划。响应按字节读取，上限1MB；服务器错误正文不会原样展示，避免错误内容泄露请求信息。TLS 验证保持系统默认，所有重定向被拒绝。

## 验证层级

`CoachClientTests` 使用本地 `URLProtocol` 协议夹具，验证配置约束、host/port 密钥隔离标识、HTTP 错误、JSON 协议、预先取消及响应上限。302 夹具验证状态码拒绝；它不是跨站服务器实际跳转的集成测试。夹具不是线上模型回答或 AI 效果验证。没有用户的服务凭据时，不宣称真实服务已连通；需要在真机配置自己的接口后验证。

实现参考：[Apple Keychain 密码保存文档](https://developer.apple.com/documentation/security/adding-a-password-to-the-keychain)、[URLSession 重定向代理](https://developer.apple.com/documentation/foundation/urlsessiontaskdelegate/urlsession(_:task:willPerformHTTPRedirection:newRequest:completionHandler:))、[URLSession.AsyncBytes.task](https://developer.apple.com/documentation/foundation/urlsession/asyncbytes/task)。
